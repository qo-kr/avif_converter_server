# Task Log - 2025-12-31

## Task: Add output format selection (AVIF/JPEG/PNG)

### Objective
Enable output format selection via `ext` and optional `Accept` header, with JPEG/PNG encoding support and PNG compression mapping.

### Steps Taken

1. **Design**: Defined output format rules (`ext` overrides `Accept`; exact MIME matching; AVIF > JPEG > PNG fallback order).
2. **Implementation**:
   - Refactored image processing to return a `DynamicImage` before encoding.
   - Added AVIF/JPEG/PNG encoders and PNG compression mapping based on `quality`.
   - Implemented JPEG alpha handling (flatten with `bg`, otherwise fall back to PNG).
3. **Docs**: Updated `README.md` and `SPEC.md` to document new parameters, format selection rules, and JPEG alpha behavior.
4. **Tests**: Updated unit tests to encode AVIF via the new pipeline.

### Results
- The server can return AVIF, JPEG, or PNG depending on `ext`/`Accept`.
- JPEG outputs remain safe for transparent sources via `bg` flattening or PNG fallback.
- PNG compression is now configurable via the existing `quality` parameter.
